
## О чём эта работа

Скрипт на Python определяет, в какой операционной системе он запущен — Windows и macOS — собирает набор параметров о текущей системе и сохраняет результат в файл формата JSON. Программа работает кроссплатформенно: один и тот же скрипт корректно запускается на всех трёх системах. 

Сначала программа определяет тип текущей операционной системы. Затем она собирает параметры ОС, оборудования и окружения запуска. После этого все собранные данные сохраняются в файл `system_info.json`. В конце в консоль выводится краткое сообщение о том, что данные успешно сохранены.

Из модулей Python задействованы только стандартные. Модуль `platform` даёт сведения об операционной системе, архитектуре и версии Python. Модуль `sys` предоставляет данные об интерпретаторе: версию, путь к нему, разрядность и максимальное целое число. Модуль `os` используется для получения количества ядер процессора и текущей рабочей директории. Модуль `socket` даёт сетевое имя компьютера. Модуль `getpass` возвращает имя текущего пользователя. Модуль `shutil` используется для получения данных о диске через функцию `disk_usage`. Модуль `locale` определяет язык системы. И, наконец, модуль `json` нужен для записи результата в файл.

Внешние модули не использовались — все данные получены средствами стандартной библиотеки Python. Утилиты командной строки операционной системы, такие как `uname`, `systeminfo` или `wmic`, не вызывались, что соответствует ограничению задания. 

Всего программа собирает семнадцать параметров, которые можно разделить на несколько смысловых групп.

- Собирается имя операционной системы — Windows или macOS. Также собирается версия ОС — детальная версия сборки, и выпуск ОС — версия релиза ядра.

- Собирается архитектура процессора, например `arm64`, `x86_64` или `AMD64`. Также собирается имя или тип процессора.

- Собирается версия Python, например `3.14.2`. Собирается разрядность Python — `64bit` или `32bit`. Собирается полный путь к исполняемому файлу интерпретатора. И собирается максимальное целое число через `sys.maxsize`, которое косвенно подтверждает разрядность системы.

- Собирается общий объём основного диска в гигабайтах. Собирается занятое место на диске в гигабайтах. И собирается свободное место в гигабайтах.

- Собирается имя текущего пользователя операционной системы. Собирается сетевое имя компьютера. Собирается рабочая директория — путь, откуда был запущен скрипт. И собирается язык системы.

Внешние модули не использовались — только стандартная библиотека Python. Утилиты командной строки операционной системы не вызывались, все данные получены через Python-модули `platform`, `sys`, `os` и `shutil`.

Скрипт проверен на macOS и написан с учётом особенностей обеих операционных систем. На Windows используется путь `C:\` для получения данных о диске. На macOS используется путь `/`. Имя ОС и версия определяются через функцию `platform.system()`, которая работает одинаково на всех системах.
